# Sanket Rajiv Saraf — Portfolio

Personal portfolio website built with **Next.js 16**, **Tailwind CSS v4**, and **Framer Motion**.

## Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4 + Clash Display font
- **Animations:** Framer Motion
- **Theme:** Light / Dark mode via `next-themes`
- **Deployment:** Vercel

## Getting Started

```bash
cd nextjs-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and connect to [Vercel](https://vercel.com) — it auto-detects Next.js. Set the **root directory** to `nextjs-portfolio/` in Vercel project settings.
